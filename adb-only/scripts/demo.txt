# 示例脚本:演示无板方案的命令语法
# 每行一条命令,`#` 开头是注释
#
# 运行方式:
#   python3 click.py run scripts/demo.txt
# 强烈建议第一次先空跑,确认坐标都对:
#   python3 click.py --dry-run run scripts/demo.txt
#
# 坐标可以用三种写法,混用没问题:
#   1. 按文字找控件(需要界面有 UI 树)   tap 确认并知悉
#   2. 绝对像素                          tap 540,1608
#   3. 百分比(推荐,换分辨率不用改)      tap 50%,69%

# ---- 1. 找目标,不点击,只打印坐标 ----
ui

# ---- 2. 按文字点击(会自动找可点击祖先并取中心) ----
tap 确认并知悉

# ---- 3. 等界面渲染(比固定 sleep 更好的是先 wait 再点) ----
wait 1.5

# ---- 4. 按百分比点击(屏幕中心) ----
tap 50%,50%

# ---- 5. 从屏幕下方上滑到上方(列表滚动) ----
swipe 50%,75% 50%,30% 300

# ---- 6. 长按 800ms ----
long 50%,50% 800

# ---- 7. 截图存档,便于事后核对点到了哪里 ----
shot after_run

# ---- 8. 返回键 ----
key BACK
