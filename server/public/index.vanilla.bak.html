📖 这是什么

一套「手机 + 触摸注入板」的自动化系统。板子以 HID 触摸屏的身份接入手机 (蓝牙或 USB),App 按流程指挥板子往手机屏幕上注入点击、滑动。

三条链路要分清:
  · HID 链路(注入触摸)  板子 → 手机,由刷 ble 还是 usb 固件决定
  · 控制链路(App 读写板子)  App ↔ 板子,走 WiFi 或 蓝牙控制通道
  · 上报链路(云端同步)  板子和 App → 这台服务器

ℹ️ 接口速查

板子(需要 X-Token: <boardToken>)
POST /api/v1/board/heartbeat · 心跳 + 拿固件更新指令
GET /api/v1/board/firmware/download/:id · 下载固件

App(需要 X-Token: <appToken>)
GET /api/v1/app/version?code=109 · 查更新(不需要 token)
GET /api/v1/app/download/:id · 下载 APK
POST /api/v1/app/phone · 上报手机信息
POST /api/v1/app/apps · 上报已装 App
GET /api/v1/app/screenshot/request · 远程截图(暂未启用,口子已留)
