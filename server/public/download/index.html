3. 下载烧录脚本和工具

烧录工具 esptool —— 烧录脚本会自己装,不用管。 想手动装:

pip install esptool

也可以用在线的 网页版烧录器(Chrome / Edge,插上 USB 就能烧)。

4. 怎么烧

Windows —— 把固件和 flash-windows.bat 放同一个目录,双击它。
Mac / Linux —— 同一个目录里:

chmod +x flash-mac-linux.sh
./flash-mac-linux.sh

烧录前 3 个检查:

  1. 板子插的是「原生 USB」口(标 USB / COM),不是标 UART / 232 的
  2. 用能传数据的数据线(有些线只供电)
  3. 找不到串口就:按住 BOOT → 点一下 RST → 松开 BOOT

5. 烧完之后

  1. 等约 10 秒,板子自动连 WiFi
  2. 手机开蓝牙,搜 ESP32-Touch 并配对
  3. 装 App → 菜单 → App 列表 → 选目标 App
  4. 设置 → 页面识别 → 开启(要无障碍权限)
  5. 流程页 → 🔍 自动查找板子

连不上 WiFi? 板子会自己开热点兜底:

SSID  ESP32-Touch-xxxx
密码  12345678
访问  http://192.168.4.1/   ← 填正确的 WiFi 名和密码

常见问题

现象解决
找不到串口换数据线;按住 BOOT 再点 RST 进下载模式;别用 USB hub
烧录报 Failed to connect同上
看不到串口日志 正常的 —— USB 口被拿去当触摸屏了。 看日志用浏览器打开 http://<板子IP>/
烧完没反应等 10 秒;看路由器 DHCP 列表;或连板子热点配网
坐标全偏 烧 自检版(开机自动点屏幕四角+中心)。 ⚠️ 它会自动触摸,先确认手机停在安全界面
