# 悬浮窗把柄改为竖排 4 按钮

## 改动前后

**改前**(横向一排):

```
[⠿][🙈][📐][◀]   ← 共 106dp 宽,占屏幕横向空间
```

**改后**(竖排一列):

```
[⠿]  ① 拖动
[🙈]  ② 暂时隐藏(让路)
[📐]  ③ 坐标拾取
[◀]  ④ 收到边框
```

每个按钮 **34dp 宽 × 30dp 高**,整体 34×120dp。

## 收到边框后的行为

```
点 [◀]  →  面板隐藏 + 只剩一个按钮,图标变成 [📋]
                      ↓
            点 [📋]  →  悬浮窗弹回来(4 个按钮 + 面板)
```

**正好对应你说的「收到边框后只显示日志按钮,点击日志后弹出悬浮窗」。**

## 实现要点

### 1. 拖拽监听必须挂在拖柄本身

```java
// ⚠️ 挂在容器上没用:各按钮都是 clickable,会先吃掉触摸事件
dragTarget = handleText;      // 只挂第 ① 个按钮
setupDrag(handleText);
```

所以**拖动只能从 `⠿` 那个按钮拖** —— 这正好符合"第一行:拖动"的设计。

### 2. 收起时把另外三个按钮 `setVisibility(GONE)`

不是重建布局,只是隐藏 + 把第①个按钮从 `34×30` 改成 `42×42`(BALL_DP)。

### 3. 贴边的位置计算要跟着改

```java
// 展开:把柄靠边,面板在它内侧
handleLp.x  = dockRight ? screenW - dp(HANDLE_W_DP) : 0;
panelLp.x   = dockRight ? handleLp.x - dp(PANEL_W_DP) + dp(4)
                        : handleLp.x + dp(HANDLE_W_DP) + dp(2);

// 收起:露出一部分在屏幕外
handleLp.x  = dockRight ? screenW - dp(BALL_DP - 6) : -dp(6);
```

`clampY()` 的上限也从写死的 `screenH - 200` 改成
`screenH - max(把柄高, 小球高) - 20`。

### 4. 面板首行的占位要缩小

原来首行给横向把柄留了 **108dp** 占位(不然把柄会盖住时间文字)。

竖排后把柄在面板**左侧**,宽只有 34dp,**不再重叠** ——
所以占位改成和下面几行一致的 **26dp**。不改的话左边会有一大块空白。

## 实测

| 项 | 结果 |
|---|---|
| 竖排 4 个按钮 | ✅ 蓝/橙/紫/灰,从上到下 |
| 点 `◀` 收到边框 | ✅ 面板消失,只剩 `📋` 贴右边 |
| 点 `📋` | ✅ 悬浮窗弹回来 |
| 面板文字对齐 | ✅ 首行与下面几行左对齐 |
| 拖动 | ✅ 从 `⠿` 拖 |
