# 选词面板:黄色文字看不清 → 深色高对比配色

## 你反馈的

> 弹出来的文字都是黄色,人眼看不清,能换个颜色吗

**原因是:我在亮色按钮上写了浅黄色文字。**

---

## 为什么会这样

`Button` 控件默认用的是**系统亮色主题**(浅灰/白底 + 深色字)。
我为了让 ⭐ 词"醒目",给它设了:

```java
b.setTextColor(0xffffd479);   // 浅黄
```

**浅黄字 + 亮灰底 = 对比度极低** —— 糊成一片。

> 同类问题:**深色 App 里用系统默认 Button,颜色一定会打架。**
> 要么自己画背景,要么改主题。

---

## 改成了什么

**自己画背景**(圆角矩形 + 描边),按「是否 ⭐」分两种:

| | 背景 | 描边 | 文字 |
|---|---|---|---|
| **⭐ 本页独有的词**(推荐) | 暗金 `#3a2d0a` | 金 `#d29922` | **亮金 `#FFE08A`** |
| 普通词(两页都有,别用) | 暗灰 `#21262d` | `#30363d` | 中灰 `#9aa4b0` |

```java
android.graphics.drawable.GradientDrawable bg =
        new android.graphics.drawable.GradientDrawable();
bg.setCornerRadius(dp(6));
if (isNew) {
    bg.setColor(0xFF3a2d0a);
    bg.setStroke(dp(1), 0xFFd29922);
    b.setTextColor(0xFFFFE08A);
} else {
    bg.setColor(0xFF21262d);
    bg.setStroke(dp(1), 0xFF30363d);
    b.setTextColor(0xFF9aa4b0);     // 刻意弱化
}
b.setBackground(bg);
```

底部的「用页面名」和「关闭」也一起做成深色,保持一致。

---

## 效果

```
╔═══════════╗ ╔═══════════╗ ╔═══════════╗
║ ⭐ 冬日熊   ║ ║ ⭐ 我的订单 ║ ║ ⭐ 关注    ║   ← 暗金底 + 亮金字
╚═══════════╝ ╚═══════════╝ ╚═══════════╝
║ ⭐ 抢票预约 ║ ║ ⭐ 想看     ║ ║ ⭐ 我的票夹 ║
  [首页]   [影院·场馆]   [大麦VIP]   [发现]     ← 暗灰底 + 中灰字
```

**两层信息现在一眼可辨:**

1. **有没有 ⭐** —— 有没有资格当 waitfor 关键字
2. **颜色强弱** —— ⭐ 是"推荐",灰色是"别用"

> ⭐ 词用**金色高亮**(推荐),非 ⭐ 词用**灰色弱化**(别用)——
> 颜色本身就在告诉你怎么选。

---

## 教训

**深色 App 里不要直接用系统默认 `Button`。**

它的背景是**亮色**的,你在上面设什么浅色文字都会对比不足。
要么 `setBackground(自己画的 GradientDrawable)`,
要么在主题里统一定义 Button 样式。
