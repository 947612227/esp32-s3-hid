# 设置与帮助分离

## 你提的三件事

> 1. 请先开启页面识别的弹窗信息
> 2. 在设置里面加个开启页面识别的入口
> 3. 设置里面太乱了,说明信息挪到帮助,设置里面只保留功能开关之类的

---

## ① 启动提醒里加了「页面识别」

**放在第 ② 条**(紧跟权限之后,因为它是"强烈建议开"的):

```
① 权限(悬浮窗 / 网络 / 无障碍)
② 页面识别(建议开启)          ← 新增
     ❌ 未开启 —— 不开的话脚本里只能用 wait 猜时间,
        页面慢一点就点空,而且失败了不知道为什么。
        → 点这里去开启(只看不点,不代替你操作)
        → 它是干什么的、打不开怎么办
③ 用之前必须准备好(否则流程必然失败)
④ 注意事项
⑤ 用途边界
```

**已开启时**显示:

```
② 页面识别
   ✅ 已开启 —— 悬浮窗会显示当前页面,脚本可以用 waitfor / ifpage
```

两个可点入口:**直接跳系统无障碍设置** / **打开详细说明**。

## ② 设置里加了页面识别入口

```
页面识别(无障碍)
  ❌ 未开启 —— 点这里去开启              ← 点它跳系统设置
  ❓ 它是干什么的 / 打不开怎么办          ← 点它看详细说明
```

已开启时显示:

```
页面识别(无障碍)
  ✅ 已开启 · cn.damai / NcovSkuActivity  (点一下去管理)
```

> **权限状态是实时的** —— 每次打开设置都会重新读。

## 新增「帮助」页(菜单 → ❓ 帮助)

```
帮助
设置里只放「能点的开关」,这里放「为什么 / 怎么办」。
点下面任意一条看详细说明。
──────────────────────────────────────
🔍  页面识别(无障碍)
    怎么开、有什么用、为什么有时不灵
──────────────────────────────────────
⌨️  打字时弹「是否连入外接键盘」
    根因是 HID 自称键盘,已修
──────────────────────────────────────
📶  板子连不上 WiFi
    首次配网 / 换网络的完整步骤
──────────────────────────────────────
📋  使用前须知
    权限 / 登录 / 抢票预约 / 购票人
──────────────────────────────────────
⚡  执行时为什么不息屏
    手机息屏最大只有分钟级,怎么办
──────────────────────────────────────
🪟  悬浮窗为什么点不动
    面板故意设成「不可触摸」的原因
──────────────────────────────────────
🎯  流程点空了怎么办
    按原因逐条排查
──────────────────────────────────────
💾  数据存在哪 / 重装会丢什么
    什么在板子上、什么在手机上
```

### 新增的 3 篇说明

| 主题 | 内容 |
|---|---|
| **页面识别** | 干什么用 / 怎么开(含 MIUI「危险」弹窗步骤)/ 只读不点 / **显示已开启但没反应就重启手机** |
| **执行时不息屏** | 为什么不常用的办法不管用 + 三重保活机制 + 权限怎么给 + **重装会重置** |
| **悬浮窗为什么点不动** | `FLAG_NOT_TOUCHABLE` 的原因(**注入的点击会被面板吃掉**) |
| **流程点空了** | **6 条排查清单** + 为什么该用 `waitfor`/`ifpage` |
| **数据存在哪** | 流程在板子 Flash / 附加信息在手机;卸载会丢什么 |

## 顺手修掉的

| 问题 | 说明 |
|---|---|
| 提示里的 `**` 字面量 | `TextView` 不渲染 markdown,`**未开启**` 会原样显示星号 —— 已清掉 |
| 中英文引号嵌套 | Java 字符串里写 `"..."` 会编译失败 —— 统一换成 `「」` |
| 设置里缺「自动查找板子」 | 之前只能改地址,不能主动找 —— 补上 |
