### ⚠️ 关键设计:为什么拆成两个窗口

Android 里**可触摸的窗口会吃掉落在它范围内的所有触摸**。
而注入是"按绝对坐标"打到屏幕上的 —— 如果悬浮窗整体可触摸,
落在它上面的注入点击会被吞掉,流程静默失败(极难查)。

但窗口设成 `NOT_TOUCHABLE` 之后,**连拖动都做不了**(子 View 也收不到触摸)。

所以拆成:
| 窗口 | 内容 | 触摸性 |
|---|---|---|
| `panelWindow` | 时间 / App / 日志 | **NOT_TOUCHABLE**,触摸 100% 穿透 |
| `handleWindow` | 拖柄 / 收起后的小球 | 可触摸,但**很小** |

### ⚠️ 两个实测踩到的坑

**坑 1:拖动监听挂在容器上没用。**
拖柄和收起按钮都是 `clickable`,会先吃掉触摸,父容器的 `OnTouchListener`
永远不触发 → 表现为"怎么拖都不动"。
**解决:把拖动监听直接挂在拖柄 View 上**,点击逻辑并入 `ACTION_UP` 处理。

**坑 2:`setVisibility(GONE)` 不会让窗口"让路"。**
把窗口的根视图设成 GONE,**窗口依然存在、依然参与触摸判定**,
拖柄位置的注入点击还是会被吃掉。
**解决:执行流程时把 handle 窗口从 `WindowManager` 真正 `removeView`,
结束后再 `addView` 回来。**

**实测验证**:执行流程时 overlay 窗口数 `2 → 1`(拖柄被移除),结束后恢复 `2`。

## P8 给板子配网 ✅

- 板子新增 `GET/POST /api/wifi`,凭据存 NVS(掉电不丢)
- App「设置 → 给板子配网」、网页控制台都有入口
- **失败自动回退**:先保存新凭据 → 尝试连接(最多 20 秒)→ 连不上就回退

### ⚠️ 这里修掉一个会导致板子"变砖"的隐患

原来的回退逻辑是"回退到 NVS 里的旧凭据"。但**首次配网时 NVS 是空的**,
这个分支会被跳过 → 板子彻底失联,只能重新烧录。

**已改为:NVS 为空时回退到编译期默认凭据(`WIFI_SSID`/`WIFI_PASS`)。**

**实测验证**:故意提交错误的 SSID `NOT_EXIST_XXXX` → 板子尝试 20 秒失败 →
自动回退 → **仍在 `192.168.5.37` 正常在线**。

## P9 频率改名 + 毫秒化 ✅

| 端 | 改动 |
|---|---|
| 板子 | `/api/schedule` 参数 `sec` → `ms`(旧 `sec` 仍兼容);按 `millis()` 计时,精度到毫秒 |
| 板子 | 状态字段 `intervalSec` → `intervalMs` |
| 网页 | 「定时循环」→「**频率**」,单位「秒」→「**毫秒**」,默认 60 → **100ms**,下限 **10ms** |
| App | 流程行新增「**频率…**」按钮,毫秒步进器(10~2000,默认 100),带开始/停止 |

**下限 10ms 的依据**(见 `docs/P0-频率实测.md`):
实测 BLE 单帧最小间隔约 11ms,每步开销约 18ms,再小没有意义。

## 本轮踩到并修掉的坑

| # | 问题 | 根因 | 修法 |
|---|---|---|---|
| 1 | **打的包缺 MainActivity** | 构建脚本用 `\|\| true` 把 javac 错误吞了,d8 拿旧 class 打了个坏包还不报错 | 编译错误必须中断 |
| 2 | javac 错误看不见 | `set -e` 让脚本在 javac 失败时直接退出,错误打印根本没执行 | javac 前后 `set +e` / `set -e` |
| 3 | 编辑器弹窗**所有按钮点不动** | 输入法弹出后,AlertDialog 上的点击被"收起键盘"吃掉 | 编辑流程改为**独立全屏页面** + 输入停顿自动收键盘 |
| 4 | 界面全空、页签消失 | 顶栏的空白 `View` 在 `AT_MOST` 下返回全部可用高度,吃掉整屏 | 给明确高度 `dp(1)` |
| 5 | `uiautomator dump` 返回**缓存**,误判"时钟不走/页签切不动" | dump 有时不刷新 | 工具里先删旧文件 + 重试 |
| 6 | 正则解析 UI XML 不可靠,导致点击落空却静默通过 | 节点嵌套/属性顺序 | 改用真正的 XML 解析器(`tools/uitap.py`) |
| 7 | 用 BACK 键收键盘,把**弹窗一起关掉** | BACK 会 dismiss 弹窗 | 测试时直接点顶部按钮 |
| 8 | 中文字符串里用了 ASCII 引号 | 字符串被提前截断 | 改用「」 |
| 9 | 配网失败可能让板子失联 | 首次配网 NVS 为空,回退分支被跳过 | 回退到编译期默认凭据 |
