# 数据怎么来的

```
流程里写:            notify 抢到了!页面已跳到付款
                          ↓
板子执行到这一步:      POST /api/v1/board/event
                          ↓
服务器:              存进 board_events 表(带 mac + flow + message + at)
                          ↓
管理界面:            SELECT ... GROUP BY mac, flow
```

**关键**:事件里带了
- `mac` → 能对应到**哪块板子**
- `flow` → 就是当时在跑的**流程名**(板子执行时自动带上的,不用你写)

所以统计天然就能区分"哪块板子、哪个流程" ✅

# 接口

```bash
# 统计(按板子+流程聚合)
curl -b cookie "http://120.55.183.206/api/admin/event-stats"
#   → { ok, summary:{total,today}, stats:[{mac,board_name,flow,total,today,last_at,last_msg}] }

# 只看最近 N 天
curl -b cookie "http://120.55.183.206/api/admin/event-stats?days=7"

# 事件明细
curl -b cookie "http://120.55.183.206/api/admin/events?limit=30"
```

SQL 长这样:

```sql
SELECT e.mac,
       MAX(COALESCE(b.name, ''))  AS board_name,     -- 板子名
       COALESCE(e.flow, '(没写流程名)') AS flow,       -- 流程名
       COUNT(*)                   AS total,          -- 成功总次数
       SUM(CASE WHEN e.at >= CURDATE() THEN 1 ELSE 0 END) AS today,
       MAX(e.at)                  AS last_at,
       MIN(e.at)                  AS first_at,
       SUBSTRING_INDEX(GROUP_CONCAT(e.message ORDER BY e.at DESC
                                    SEPARATOR '\n'), '\n', 1) AS last_msg
FROM board_events e
LEFT JOIN boards b
  ON b.mac COLLATE utf8mb4_unicode_ci = e.mac COLLATE utf8mb4_unicode_ci
WHERE e.type = 'flow_event'
GROUP BY e.mac, e.flow
ORDER BY total DESC, last_at DESC
```

# 踩的两个坑

## ① `Illegal mix of collations` —— 建表没写 COLLATE

新表 `board_events` 用了库默认的 `utf8mb4_0900_ai_ci`,
而早期建的 14 张表都是 `utf8mb4_unicode_ci` ⇒ JOIN 直接报错 ✅

**修**:`ALTER TABLE ... CONVERT TO ... COLLATE utf8mb4_unicode_ci`,
并且 JOIN 里**显式写 COLLATE** 双保险 ✅

> **教训:CREATE TABLE 一定要显式指定字符集和排序规则。**
> 看着一样的 `utf8mb4`,默认值在不同 MySQL 版本/配置下是不一样的。

## ② `only_full_group_by` —— 聚合列没包起来

```
Expression #2 of SELECT list is not in GROUP BY clause and contains
nonaggregated column 'touchpad.b.name'
```

MySQL 8 默认开启 `only_full_group_by` ✅
`GROUP BY e.mac, e.flow` 而 SELECT 里有 `b.name` ⇒ 报错 ✅

**修**:`MAX(COALESCE(b.name, '')) AS board_name` ✅

> 顺带说:这次报错**服务没崩** —— 因为上一轮刚加了 try/catch + 全局兜底 ✅
> 只返回了一个 `500 {"message":"..."}`,页面显示红色提示 ✅
> **同一个错误,上午让整站下线,现在只影响一个接口。**
