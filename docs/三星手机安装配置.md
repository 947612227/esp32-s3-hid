## 三、⚠️ 踩到一个**必崩**的坑(Android 14+ 通病)

### 现象

清单里声明了前台服务类型:

```xml
<service android:name=".KeepAliveService"
         android:foregroundServiceType="dataSync" />
```

**但没声明对应的权限。**

### 后果

**Android 14(API 34)起**,用了 `foregroundServiceType` 就**必须**声明
`FOREGROUND_SERVICE_<TYPE>` 权限 ✅ 否则 `startForeground()` 抛
**`SecurityException`** ⇒ **App 直接崩** ✅

> 之前那台小米是 **Android 10**,碰不到这规则 ✅
> 三星是 **Android 16**,一开页面识别就崩 ✅

### 修法

```xml
<uses-permission android:name="android.permission.FOREGROUND_SERVICE" />
<!-- ⚠️ Android 14+ 必须:服务声明了 type=dataSync 就要这条 -->
<uses-permission android:name="android.permission.FOREGROUND_SERVICE_DATA_SYNC" />
<!-- Android 13+ 通知权限(前台服务的常驻通知) -->
<uses-permission android:name="android.permission.POST_NOTIFICATIONS" />
```

**通知权限还要运行时申请**(Android 13+):

```java
private void askNotificationPermission() {
    if (Build.VERSION.SDK_INT < 33) return;
    if (checkSelfPermission("android.permission.POST_NOTIFICATIONS")
            == PackageManager.PERMISSION_GRANTED) return;
    requestPermissions(new String[]{"android.permission.POST_NOTIFICATIONS"}, 9001);
}
```

> **教训:`foregroundServiceType` 和 `FOREGROUND_SERVICE_*` 权限是成对的。**
> 清单里写了一个就必须写另一个 —— 而且**在老 Android 上完全不报错**,
> 一到新系统就崩 ✅

## 四、三星(One UI)必须配的 5 项

**⚠️ 三星的设置路径和小米完全不一样**,别照 MIUI 的教程找 ✅

### ① 无障碍(页面识别)

```
设置 → 辅助功能 → 已安装的应用程序 → 触摸注入板 → 开启
```

### ② 电池:不受限制 ← **三星杀后台主要靠这个**

```
设置 → 电池和设备维护 → 电池 → 后台使用限制
   · 「自动运行应用程序」→ 把「触摸注入板」打开
   · 「使未使用的应用程序进入休眠」→ 确认没勾上它
```

再补一道:

```
设置 → 应用程序 → 触摸注入板 → 电池 → 选「不受限制」
```

### ③ 通知权限

首次打开 App 会弹窗 → 选**允许** ✅
(不给也能跑,但看不到「App 还活着」的常驻通知 ✅)

### ④ 锁定后台

```
打开最近任务 → 长按「触摸注入板」卡片 → 点「锁定」
```

### ⑤ 关闭「自动优化」

```
设置 → 电池和设备维护 → 右上角 ⋮ → 自动化 → 关闭「自动优化」
```

> 开着的话三星会**按使用习惯**把不常用的 App 冻结 ✅
> 我们的 App 恰恰是"平时不用、抢票时才用",最容易被优化掉 ✅

## 五、App 内的帮助已经按品牌自动切换

以前帮助里**只写了 MIUI**,在三星上照着找根本找不到 ✅

现在按 `Build.MANUFACTURER` 自动选:

```java
if (brand.contains("samsung")) {
    // 三星的五步
} else if (brand.contains("xiaomi") || brand.contains("redmi") || brand.contains("poco")) {
    // 小米的三项
} else {
    // 通用:自启动 / 电池不受限 / 锁定后台 / 通知
}
```

**入口**:App → 菜单 → 帮助 → 「🛡 App 老是被杀 / 页面识别老断」

## 六、和小米的对比

| | 小米(MIUI) | 三星(One UI) |
|---|---|---|
| 自启动 | **必需**,在应用管理里 | 在「后台使用限制 → 自动运行应用程序」 |
| 省电 | 「省电策略 → 无限制」 | 「电池 → 不受限制」 |
| 冻结 | 无 | **「自动优化」要关掉** |
| 锁定后台 | 卡片下拉加锁 | 长按卡片 → 锁定 |
| 无障碍 | 有时卡在「正在绑定」 | 相对稳 |
| 重装后 | **必须重启手机** | 实测重装后直接能用 |
