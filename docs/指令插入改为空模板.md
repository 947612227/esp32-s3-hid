# 指令插入:只插指令本身,不预填参数

## 需求

点快捷指令时,原来会插入**一整条带数值的示例**:

```
点「T 点击」 →  T 0.5 0.5 60      ← 这三个数值每次都要手动删掉
```

改成**只插指令本身**,参数留空手填:

```
点「T 点击」 →  T
点「H 长按」 →  H
```

**例外**:`wait` 给一个默认时长(需求指定 1500)。

```
点「wait 等待」 →  wait 1500
```

## 为什么

坐标这类值:
- 用**拾取器**拿(悬浮窗 📐)比手敲准;
- 或者是特定界面上的固定位置,预填的 `0.5 0.5` 永远不对。

预填了反而**每次都要删**,不如留空。

## 改了什么

| 位置 | 原来 | 现在 |
|---|---|---|
| **快捷指令条** | 5 条固定指令,插入示例 | **全部 12 条**、横向可滚动,插入空模板 |
| **指令库长按** | 插入示例 | 插入空指令 |
| 指令库**点按** | 打开参数页 | 不变(那是专门调数值的) |
| 参数页「插入」 | 按滑块生成整行 | 不变(这是它的用途) |

## 实现

`CmdLib.Cmd` 增加 `template` 字段(默认 = 指令 + 一个空格),
`wait` 显式指定 `"wait 1500"`:

```java
public static String template(Cmd c) { return c.template; }
```

以后加新指令,默认模板自动是 `字母 + 空格`,要特殊默认值就在构造时传。

## 实测

| 操作 | 结果 |
|---|---|
| 点「H 长按」 | 内容框出现 `H ` ✅ |
| 点「wait 等待」 | 内容框出现 `wait 1500` ✅ |
| 快捷条覆盖 | 滚到尾部可见 `V / wait / repeat / goto` ✅ |
| 生成的行 | 无多余数值 |
