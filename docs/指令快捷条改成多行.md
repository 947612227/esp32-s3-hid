# 指令快捷条:横向滑动 → 自动折成多行

## 你反馈的

> 新建和编辑流程的指令快捷键弄成两行或者多行,不要左右滑动切换。
> 或者弄个弹窗,点击指令后关闭弹窗即可。

**改成了自动折行 —— 16 条指令全部可见,不用左右滑。**

---

## 改前

一个 `HorizontalScrollView`,16 条指令挤在一行里,**要左右滑**才能看到后面的:

```
[T 点击] [D 双击] [H 长按] [S 直线滑动] →→→  (滑动才能看后面的)
```

## 改后

按屏幕宽度**自动折行**,现在是 **4 行**:

```
[T 点击]        [D 双击]        [H 长按]      [S 直线滑动]
[P 双指滑动]     [Z 捏合缩放]     [K 键盘按键]   [V 多媒体键]
[wait 等待]     [repeat 重复]   [goto 跳转]   [waitfor 等待页面]
[ifpage 如果是页面]  [else 否则]      [endif 结束判断]
```

**没有横向滚动了** —— 一屏看全。

---

## 怎么算折行的

Android 没有内置的"流式布局"(Flexbox 需要额外依赖,而这个工程不用 Gradle),
所以**自己量文字宽度、自己决定换行**:

```java
android.graphics.Paint pm = new android.graphics.Paint();
pm.setTextSize(sp(11));                       // 和 Button 字号一致
int maxRowW = screenW - dp(44);               // 减去左右 padding

LinearLayout rowNow = null;
int rowUsed = 0;
for (CmdLib.Cmd cc : CmdLib.all()) {
    String label = cc.letter + " " + cc.name;
    int w = (int) pm.measureText(label) + dp(24);   // 估算按钮宽度

    if (rowNow == null || (rowUsed > 0 && rowUsed + w > maxRowW)) {
        rowNow = 新建一行();                        // 放不下就换行
        rowUsed = 0;
    }
    加按钮到当前行();
    rowUsed += w + dp(4);
}
```

> **行数会跟着屏幕宽度自动变** —— 窄屏更多行,宽屏更少。
> 不写死"几行",所以换设备也不会错位。

### 顺带把按钮做紧凑了

| | 改前 | 改后 |
|---|---|---|
| 高度 | 34dp | **30dp** |
| 左右内边距 | 10dp | 8dp |
| 行间距 | 无 | 4dp |

4 行总共约 136dp。

## 另一个方案(你说的弹窗):其实已经有了

「**⛭ 指令库**」按钮就是一个全屏选择页:

| 操作 | 效果 |
|---|---|
| **点一下指令卡片** | 进**参数编辑页**(滑块 + 备注 + 坐标拾取)→ 点「插入」 |
| **长按指令卡片** | **直接插入指令本身**然后关闭 ✅ |
| 左上「← 返回」 | 关掉,什么都不做 |

所以"点击指令后关闭弹窗"这个需求,用**长按**就能达到 ——
而且比点一下更不容易误触(点一下是进参数页,更常用)。

---

## 为什么没做成纯弹窗

两种方案对比:

| | 多行快捷条(选了这个) | 弹窗 |
|---|---|---|
| 常用指令 | **一眼看到,一下点到** | 要多点一次打开弹窗 |
| 占用空间 | 4 行 ≈136dp | 0(收起来了) |
| 编辑框空间 | 少 136dp | **全给编辑框** |

**多行更适合"经常插指令"的场景** —— 少一次点击。
如果以后觉得占地方,把 `chipBox` 折成「2 行 + ⋯ 更多」也很容易改。

## 实测

| 场景 | 结果 |
|---|---|
| 编辑器打开(无键盘) | 4 行 16 条全可见 ✅ |
| 键盘弹出 | 4 行全在 + 参考信息让位 + 编辑框 5 行 ✅ |
| 点「T 点击」 | 在光标处插入 `T ` ✅ |
| 退出不保存 | 流程内容**没被改动**(仍 13 步)✅ |

---

## 教训

**"横向滑动"是最容易被忽略的可用性问题** ——
开发时自己知道右边还有东西,用户却经常**根本不知道能滑**,以为就那几个指令。

**能一屏放下就别藏起来。**
