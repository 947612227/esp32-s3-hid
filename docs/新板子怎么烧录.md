# 一块新板子怎么烧录固件

# 〇、最省事的办法:直接从服务器下载烧录包

**打开 http://120.55.183.206/download/** —— 不用登录,固件/脚本/说明全在。

| 下载什么 | 说明 |
|---|---|
| `touchpad-ble-full.bin` | 固件 · **蓝牙版(推荐)** |
| `touchpad-usb-full.bin` | 固件 · USB 版 |
| `touchpad-usb_touchtest-full.bin` | 固件 · **自检版**(开机自动点四角验证坐标) |
| `flash-windows.bat` | **Windows 一键烧录** |
| `flash-mac-linux.sh` | **Mac / Linux 一键烧录** |
| `README.txt` | 烧录说明 |

**用法**:把固件和脚本下载到**同一个目录**,双击 / 执行脚本就行。
脚本会自动装 `esptool`、自动找串口、自动烧录。

> **单文件固件**:已经把 `bootloader` + `partitions` + `boot_app0` + `firmware`
> 四段合并成一个 `full.bin`,烧到 `0x0` 就行 —— **不用记任何偏移地址**。

**重新发布固件**(改了代码之后):

```bash
./tools/release-firmware.sh -n "这次改了什么"
```

它会:编译三个环境 → 合并成单文件 → 打包脚本 → 上传到 `/download/`。

# 一、下面是自己编译的完整流程

## 一、硬件要求

| 项 | 要求 |
|---|---|
| 芯片 | **ESP32-S3** —— 必须是 S3,不是 S2/C3 |
| Flash | **8MB** |
| PSRAM | **8MB,必须是 OPI(八线)** —— 也就是俗称的 **N8R8** |

> ⚠️ **N8R2 / N16R8 都不行**(或要改 `platformio.ini`)。
> 固件里写死了 `board_build.arduino.memory_type = qio_opi`,
> 且分区表按 8MB Flash 编排。

**买的时候搜「ESP32-S3 N8R8 开发板」** ✅

---

## 二、一次性准备(只做一次)

```bash
# 1. 装 PlatformIO(已经有就跳过)
pip install platformio

# 2. 进工程目录
cd ~/workspace/esp32s3-hid-touch

# 3. 准备配置文件
cp secrets.example.h secrets.h
```

### 编辑 `secrets.h`

```c
#define WIFI_SSID "你的WiFi名"          // ⚠️ 必须是 2.4G,ESP32 不支持 5G
#define WIFI_PASS "你的WiFi密码"
#define AP_SSID_PREFIX "ESP32-Touch"    // 连不上 WiFi 时开的热点名
#define AP_PASS "12345678"              // 至少 8 位
#define SERVER_URL    "http://120.55.183.206"
#define SERVER_TOKEN  "board_e3885992707932aee22fa85e1d565e55"
#define HEARTBEAT_MS  (2UL * 60UL * 1000UL)
```

> **多块板子用同一份 `secrets.h` 就行** ——
> 服务器靠 **MAC 地址**区分板子,不用为每块板子改配置 ✅
> 想给每块板子起不同名字,烧完在 App 或网页里改。

## 三、烧录

### 一键(推荐)

```bash
./tools/flash.sh ble fresh
```

| 参数 | 说明 |
|---|---|
| `ble` | **BLE HID 版(推荐)** —— 蓝牙直接连手机,不占 USB 口 |
| `usb` | USB HID 版 —— 需要 OTG 转接,但延迟更低 |
| `usb_touchtest` | 自检版 —— 开机 1.5 秒后自动点屏幕四角+中心,验证坐标 |
| `fresh` | **先全片擦除再烧**(新板子 / 换过分区表时必须) |
| 第三个参数 | 手动指定串口,如 `/dev/cu.usbmodem1234` |

### 手动(等价)

```bash
pio run -e ble                        # 编译
pio run -e ble -t erase               # 全片擦除(新板子)
pio run -e ble -t upload              # 烧录
```

### 板子要插哪里

**插 ESP32-S3 的「原生 USB」口**(通常标着 `USB` 或 `COM`),
不是标 `UART` / `232` 的那个 ✅

插上后 Mac 上会出现 `/dev/cu.usbmodem*`:

```bash
ls /dev/cu.usbmodem*
```

**没出现?** 按板子上的 `BOOT` 键不放,点一下 `RST`,再松开 `BOOT`,
进入下载模式后重试 ✅

## 四、验证板子活了

```bash
./tools/find_board.py
```

它会:
1. **问服务器** —— 板子 2 分钟一次心跳,服务器记着它的 IP
2. **UDP 广播** —— 和板子同网段时最准
3. **HTTP 确认** —— 拿到 IP 后确认真的是板子

输出长这样:

```
════ ① 问服务器 ════
  🟢 在线  192.168.5.37  ac:a7:04:26:5e:40  fw=1.2.0
        最后心跳 12 秒前 · 公网 117.133.86.219 · 北京
        ✅ 板子在 192.168.5.37,流程 7 个,HID 就绪
        → http://192.168.5.37/
```

> ⚠️ **UDP 广播跨不了网段** ——
> 电脑接有线、板子接另一个路由器时,广播出不去,只能靠服务器那条路。

## 五、⚠️ 原生 USB 口**看不到串口日志**

固件里是这两行:

```ini
-DARDUINO_USB_MODE=0          ; 用硬件 USB
-DARDUINO_USB_CDC_ON_BOOT=0   ; Serial **不**重定向到 USB
```

**原因**:USB 口被 TinyUSB 拿去当 HID 设备了(它要伪装成触摸屏)✅
所以 `Serial` 走的是 **UART0**(GPIO43/44)✅

**想看日志,三个办法:**

| 办法 | 命令 |
|---|---|
| **网络** ✅ 最方便 | `curl -s http://192.168.5.37/api/logs` |
| 板子网页 | 浏览器打开 `http://192.168.5.37/` |
| 接 USB-TTL | 接到 UART0 的 TX/RX,`pio device monitor -b 115200` |

## 六、第一次上电会发生什么

```
1. 上电 → 串口打印版本、初始化 HID
2. 连 WiFi(用 secrets.h 里配的)
3. 启动 Web 服务:http://<板子IP>/
4. 启动 UDP 发现服务(45678)
5. 上电 8 秒后发第一次心跳给服务器
6. 之后每 2 分钟一次心跳
```

**WiFi 连不上怎么办?**

板子会自己开热点兜底:

| | |
|---|---|
| 热点名 | `ESP32-Touch-xxxx` |
| 密码 | `12345678`(secrets.h 里的 `AP_PASS`) |
| 管理地址 | `http://192.168.4.1/` |

用手机连这个热点 → 打开 `192.168.4.1` → 填正确的 WiFi 名和密码 → 保存 ✅

## 七、烧完之后:接手机

1. **手机上开蓝牙**,搜 `ESP32-Touch`(或你改的名字),配对
2. **装 App**:`android-app/build/触摸注入板.apk`
3. **App → 菜单 → App 列表** → 选目标 App(如大麦)
4. **设置 → 页面识别** → 开启(需要无障碍权限)
5. **流程页 → 🔍 自动查找板子** → 认到板子
6. 写流程、跑 ✅

> **新板子第一次跑之前建议先烧 `usb_touchtest`** ——
> 开机会自动点屏幕四角+中心,一眼看出坐标映射对不对 ✅
> ⚠️ 它会自动触摸,**先确认手机停在安全界面**。

## 八、常见问题

| 现象 | 原因 / 解决 |
|---|---|
| `ls /dev/cu.usbmodem*` 没有 | 换数据线(有些只供电);按住 BOOT 再点 RST 进下载模式 |
| 烧录报 `Failed to connect` | 同上;或换个 USB 口(别用 hub) |
| 烧完没反应 | 看 `/api/status`;不行就 `fresh` 全片擦除重烧 |
| 板子找不到 | 看路由器 DHCP 列表;或连板子热点 `192.168.4.1` |
| 服务器上看不到这块板子 | 等 2 分钟(心跳周期);或看板子日志 `[net] 心跳成功` |
| HID 未连接 | 手机上蓝牙没配对;重新配对一次 |
| **坐标全偏** | 烧 `usb_touchtest` 自检版,看点和实际位置的偏差 |
