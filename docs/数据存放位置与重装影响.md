# 流程存在哪 + 重装 APK 会不会丢

## 结论(实测)

| 操作 | 板子上的流程 | App 本地的设置 |
|---|---|---|
| **新建流程** | ✅ 完全不影响 | ✅ |
| **覆盖安装 APK**(`adb install -r`) | ✅ **9 个全在** | ✅ **全部保留** |
| **彻底卸载 + 重装** | ✅ **9 个全在** | ❌ **被清空** |

**核心原因:流程根本不在 App 里,在板子上。**

## 数据分成两份

### ① 流程本身 → 存在板子 Flash(LittleFS)

```
板子 /scripts/            ← 流程文件
```

API 也在板子上:`/api/scripts`(列表)、`/api/delete`(删除)…

所以 **App 卸载、重装、换手机、用电脑浏览器**,流程都不受影响。

### ② App 本地设置 → 存在手机 SharedPreferences

```
目标 App 选择 · 定时设置 · 开启状态 · 流程创建时间 · 坐标拾取记录
```

这部分**只在手机上**,卸载就没了(Android 的沙箱机制,正常行为)。

## 实测过程

**① 覆盖安装**

```
重装前:9 个流程 · 目标 App=大麦
adb install -r
重装后:9 个流程 · 目标 App=大麦 ✅
```

**② 彻底卸载**

```
adb uninstall com.dsh.touchpad
板子上的流程 → 9 个,一个没少 ✅
(App 本地设置此时已被系统清掉)

重新安装后:
  目标 App 显示「还没有选目标 App」  ← 本地设置丢了
  板子流程仍然是 9 个              ← 流程没丢
```

## 哪些操作才会真的删掉流程

**只有两条路**:

1. 在 App / 网页里**手动点「删除」**(走板子的 `/api/delete`)
2. **给板子重新烧录固件**时如果选了"擦除 Flash"

除此之外(新建、编辑、重装 App、重启板子)**都不会删流程**。

> ⚠️ 注意:`Scripts.remove()` 只是删文件,但如果你给板子做
> `pio run -t erase` 或者刷分区表,`/scripts` 会一起没。

## 「全局只能开一个流程」的说明

App 里有个约束:**同一时间只能开启一个流程**。开启新的会自动暂停其他流程。

这是**改状态,不是删除** —— 流程内容还在,随时能再开启。

## 如果要更保险

App 的本地设置(定时等)现在只存手机。如果希望**重装 App 也不丢**,
可以把这份设置同步存到板子上(板子 LittleFS 还有空间)。

需要的话可以加:App 启动时从板子拉回设置,改动时回写。
