# 定时状态管理(编辑 / 过期 / 未开启)

## 需求

1. 编辑后的流程,如果新时间还没过期 → **更新状态和文案**
2. 过期的流程 → **自动设为暂停**
3. 未开启的流程 → **只展示倒计时,不执行**

## 一、编辑后更新状态(原来有 bug)

### 问题
改完定时后,流程**再也不会执行**了。

### 原因
调度器的执行条件是 `if (!m.fired && ...)`,但保存定时时**没有重置 `fired`**:

```java
m.atMillis = ...;          // 时间更新了
m.startAtMillis = ...;
// ❌ fired / appLaunched 还是上一次的值
flows.put(m);
```

所以:一个已经跑过(或被判定过期)的流程,把时间改到未来,
`fired` 仍是 `true` → 永远不执行;列表文案也停在旧状态。

### 修法
`FlowStore.Meta` 加 `resetRunState()`,保存定时后调用:

```java
public void resetRunState() {
    fired = false;
    appLaunched = false;
    firedAt = 0;
}
```

```java
m.resetRunState();
flows.put(m);
toast("定时已保存(已重置执行状态)");
renderScripts();
```

### 实测
```
改前:回桌面  定时:10-02 19:33:35 · 已过期
改成「30 分钟后」
改后:回桌面  定时:10-02 20:06:04 · 还有 29 分 20 秒   ✅
```

## 二、过期自动暂停

### 原来
过期只是**排序沉底**,`enabled` 还是 `true`。

问题:过期了还挂着「已开启」会让人以为它还会跑;
而且它是"全局唯一开启"的占用者 —— **不释放就没法开启别的流程**。

### 现在
每秒检查一次,发现「已开启 + 已过期」就自动暂停:

```java
private void autoPauseExpired(long now) {
    boolean changed = false;
    for (String nm : flows.allNames()) {
        FlowStore.Meta m = flows.get(nm);
        if (!m.enabled) continue;              // 幂等:暂停过的不再处理
        if (m.targetMillis() <= 0) continue;
        if (!m.expired(now)) continue;
        m.enabled = false;
        flows.put(m);
        changed = true;
        toast("「" + nm + "」定时已过期,已自动暂停");
    }
    if (changed && tab == TAB_SCRIPTS) renderScripts();
}
```

**幂等**:暂停后 `enabled` 就是 `false`,不会重复触发;
只有真的改了状态才重排列表(避免每秒重建视图导致点击落空)。

**定时记录保留不清理** —— 只是暂停,"这个流程本来定过某个时间"仍然看得到。

### 实测
```
开启「回桌面」,1 分钟后到点 → 执行 → 再过 60 秒
结果:○ 回桌面  定时:10-02 19:33:35 · 已过期   ✅ 已自动暂停
```

## 三、未开启的流程只展示倒计时,不执行

**这条本来就是现有行为**,一并确认:

调度器只处理**全局唯一开启**的那个流程:

```java
String name = flows.enabledName();
if (name == null) return;      // 没有开启的 → 整个调度器不动
```

所以未开启的流程:
- ✅ 列表里**照常显示倒计时**(知道它"如果开启会在什么时候跑")
- ✅ 到点**不会执行**

配合第 2 条,现在的状态机是:

```
设置定时 + 开启
      ↓
T-5min  启动目标 App
      ↓
T       执行流程(fired=true)
      ↓
T+60s   判定过期 → 自动暂停(记录保留)
```

## 状态总览

| 状态 | 列表标记 | 定时文案 | 会执行吗 |
|---|---|---|---|
| 未设置定时 | ○ | 定时:未设置 | 只有手动点「运行」 |
| 有定时 + 未开启 | ○ | 还有 X 分 X 秒 | ❌ 只展示 |
| 有定时 + 已开启 | ● | 还有 X 分 X 秒 / 正在执行 | ✅ |
| 已过期 | ○(自动暂停) | 已过期 | ❌ |
