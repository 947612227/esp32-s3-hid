# 输入法老是自己缩回去 —— 原因和修复

## 现象

点输入框,键盘弹出来,**过 1 秒多就自己收回去**,根本没法连续打字。

## 根因:**是我自己加的"自动收键盘"**

`FlowEditActivity` / `MainActivity` 里有个 `wireAutoHide()`:

```java
// 打字停止 1.3 秒后 → 收起键盘 + 清掉焦点
et.addTextChangedListener(new TextWatcher() {
    public void afterTextChanged(Editable e) {
        ui.postDelayed(hideKbRunnable, 1300);   // ← 元凶
    }
});
```

**三处都挂了这个**:
- 编辑流程 → 流程名
- 编辑流程 → 流程内容
- 设置 → 板子地址 / WiFi 密码(走 `mkEdit`)

## 为什么会写出这种东西

早期遇到一个真问题:**弹窗里有输入框时,键盘弹出来盖住按钮,
点「取消」都没反应。**

我当时判断是"键盘在干扰点击",于是用"自动收键盘"绕过去 ——
**问题被掩盖了,但引入了新问题(就是你现在遇到的)**。

## 真正的根因

`AppPicker` 给弹窗设了:

```java
w.setSoftInputMode(SOFT_INPUT_ADJUST_NOTHING);   // ← 真正的病根
```

`ADJUST_NOTHING` = **键盘弹出来时窗口完全不调整**。于是:

```
┌─────────────────┐
│  弹窗内容        │
│  [输入框]        │
├─────────────────┤  ← 键盘从这里盖上来
│  键盘            │
│  [取消][保存]  ← 按钮被压在键盘下面
└─────────────────┘
```

"点了没反应"**不是键盘干扰事件**,而是**你点在键盘窗口上了**,按钮根本收不到。

## 修复

| 改动 | 说明 |
|---|---|
| **删掉 `wireAutoHide`**(3 处) | 不再自动收键盘 |
| `ADJUST_NOTHING` → **`ADJUST_RESIZE`** | 键盘弹出时弹窗自己缩上去,按钮始终可见可点 |

## 实测验证

| 位置 | 点完后 4 秒 | 打字结果 |
|---|---|---|
| 流程名输入框 | `mInputShown=true` ✅ | `大麦ABC123` ✅ |
| 流程内容输入框 | 键盘保持 ✅ | 正常 ✅ |
| 板子地址弹窗 | `mInputShown=true` ✅ | `192.168.5.377` ✅ |

(修复前:1.3 秒后 `mInputShown` 变 `false`)

弹窗的键盘模式由清单统一保证:

```xml
<activity android:name=".MainActivity"
    android:windowSoftInputMode="adjustResize" />
```

## 教训

> **用"绕过"的办法解决 bug,几乎一定会留下新 bug。**
>
> 我当时没搞清楚"为什么点了没反应",只看到"键盘在的时候就有问题",
> 于是让键盘消失 —— 症状没了,病根还在,还多了个更烦人的毛病。
>
> 正确的做法是先定位到 `ADJUST_NOTHING` 这个具体配置,再改它。
