# 流程备注怎么加

## 你问的

> 新建流程的备注怎么加

**功能一直是好的,只是没有入口提示 —— 所以找不到。**

---

## 两种写法(效果完全一样)

### 写法 ①:直接在「流程内容」框里写(最快)

参数**后面**接中文:

```
T 0.5 0.5 60 点我的票
wait 3000 等页面加载
S 0.5 0.75 0.5 0.25 260 上滑列表
```

**规则**:参数后面**第一个不是数字的词**开始,后面全算备注。

所以 `T 0.5 0.5 点我的票`(省略 ms)也认 ——
解析器看到 `点我的票` 不是数字,就知道参数到头了。

### 写法 ②:用「⛭ 指令库」(可视化)

```
流程 → 新建流程 / 编辑
  → ⛭ 指令库
  → 点一条指令(如「T 点击」)
  → 参数编辑页:
        X 坐标        0.500    [滑块]
        Y 坐标        0.500    [滑块]
        持续 ms       60       [滑块]
        ─────────────────────────────
        备注(可选)—— 写这一步在干什么,日志会优先显示它
        例:点我的 / 上滑列表 / 等页面加载      ← 就是这个输入框
        ─────────────────────────────
        将要插入的这一行:
        T 0.500 0.500 60 click_my_tickets      ← 自动拼上了
  → 点「插入」
```

**实测**(用 adb 输入 `click_my_tickets`):

```
备注框填:  click_my_tickets
预览行:    T 0.500 0.500 60 click_my_tickets     ← 备注自动拼到行尾
```

---

## 加了备注有什么用

| 没备注 | 有备注 |
|---|---|
| 日志显示 `点击 0.500 0.500` | 日志显示 **`点击:点我的票`** |

过几天回来看,还知道这一步在干什么。

**编辑流程时备注不会丢** —— 文本 → 可视化 → 文本 来回切都保留。

> **不写也完全可以**,功能一模一样,只是日志显示坐标而已。

---

## 为什么之前找不到

功能是**有**的(在指令库的参数编辑页里),但:

1. **流程编辑器里没有任何提示** —— 不提"备注"这两个字
2. 指令库页面上也没提
3. 「流程内容」框的占位提示只有 `例:T 0.5 0.5 60`,**看不出来后面还能写字**

## 改了什么

### ① 流程内容框的占位提示带上备注

```
改前: 例:T 0.5 0.5 60 · 或点上方「指令库」插入
改后: 例:T 0.5 0.5 60 点我的票   ← 参数后面的中文就是备注
```

### ② 编辑器里加一行显眼的说明(可点)

```
💬 备注:在参数后面直接写中文,例 T 0.5 0.5 60 点我的票  ← 点这里看详细说明
```

点开是个完整说明弹窗,讲清两种写法、规则、有什么用。

### ③ 标题文字顺带修正

```
改前: 每行一个动作。看不懂就点「指令库」
改后: 每行一个动作。不会写就点「指令库」
```

("看不懂"→"不会写" 更准确)

## ⚠️ 这次踩的一个坑:我的改动**第一次没生效**

第一次改完脚本打印了「已加备注提示」,但 **`grep -c "备注怎么加"` = 0** ——
锚点 `box.addView(bodyBox);` **根本不存在**(实际代码是 `textPanel.addView(bodyEd, …)`),
`str.replace()` 什么都没替换,**而我的脚本无条件打印了成功**。

装到手机上验证时才发现编辑器里没有新提示。

**教训**:

```python
# ❌ 错:replace 不检查
s = s.replace(old, new)
print("已修改")            # 不管成没成都说成功

# ✅ 对:先断言
assert old in s, "锚点没找到"
s = s.replace(old, new, 1)
```

**改完必须验证字符串真的在里面**,不能信脚本的打印。
