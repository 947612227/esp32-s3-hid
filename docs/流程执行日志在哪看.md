# 流程执行日志在哪里看

## 四个入口

| # | 入口 | 怎么进 | 特点 |
|---|---|---|---|
| **①** | **App → 日志页签** | App 顶部点「日志」 | **最方便**,每 2 秒自动刷新,可选中复制 |
| **②** | **悬浮窗下半部分** | 直接看 | 不用切回 App,但只显示最近 30 行 |
| **③** | **板子网页控制台** | 浏览器打开板子 IP(如 `http://192.168.5.37/`) | 手机/电脑都行,**不用装 App** |
| **④** | **接口** | `curl http://192.168.5.37/api/logs` | 给脚本/自动化用 |

> 板子 IP 变了就在 App 里点「🔍 自动查找板子」。

# 日志怎么读

## 前缀

| 前缀 | 含义 |
|---|---|
| `[script]` | **流程执行**(你最关心的) |
| `[net]` | 网络 / Web 请求 |
| `[web]` | 网页控制台的操作用 |
| `[boot]` | 开机 |
| `[ble]` | 蓝牙连接 |

## 逐行格式

```
[script] [3/13] 等待页面:homepage
         └┬─┘ └┬┘ └───┬───┘
          │    │      └── 备注(你写在脚本里的中文)
          │    └───────── 第几步 / 共几步
          └────────────── 指令类型
[script]   → 超时,继续执行(等了 15062 ms,当前页面:(未知))
           └───────────────────┬──────────────────┘
                    这一步的结果 + 当前实际页面
```

## 人类语言的备注

写了备注的步骤,日志显示**你的话**而不是坐标:

```
不写备注: [script] [1/3] 点击 (92%, 91%)
写了备注: [script] [1/3] 点击:点我的票
```

> 备注写法:`T 0.923 0.911 60 点我的票`
> **规则:参数后面第一个不是数字的词开始,后面全算备注。**

# ⚠️ 这轮修掉的三个日志问题

## 问题① 日志被"页面推送"刷屏

```
[net] 收到页面推送:cn.damai...NcovSkuActivity
[net] 收到页面推送:cn.damai...NcovSkuActivity    ← 每 5 秒一条(限流后)
```

**实测 80 行里 70 多行都是这个** —— 真正的流程日志被淹了。

**修法**:页面推送**不再写日志**(当前页面在悬浮窗和 `/api/page` 都能看,不需要往日志里塞)。

## 问题② 日志框写死 480dp,**长日志被裁掉**

```java
c.addView(logView, new LayoutParams(MATCH_PARENT, dp(480)));   // ← 固定高度
```

`TextView` 内容超过 480dp 就裁掉了 —— **一次 30+ 行的流程日志后面根本看不到**。

**修法**:高度改成 `WRAP_CONTENT`,交给外层 ScrollView 滚动。
顺带把字号 11→12、颜色调亮、加行距、**可以选中复制**。

## 问题③ 日志缓冲只有 80 行

一个 27 步的流程会写 30+ 行,**跑两次就把前面的顶掉了**。

**修法**:`LOG_RING_LINES 80 → 150`(内存 +11KB,板子还有 128KB 空闲)。

# 附:又踩了一次 UTF-8 截断

修 `/api/status` 的时候,我在里面写了:

```cpp
if (pt.length() > 90) pt = pt.substring(0, 90);   // ← 从中文**字符中间**切了
```

结果整个 `/api/status` 的 JSON **解析不了**:

```
UnicodeDecodeError: invalid continuation byte
```

**和之前备注截断是同一类问题,我在新代码里又犯了一次。**

**修法**:把之前写的 `copyNote` 提升成公共函数 `utf8Truncate()`,
放进了 `script_engine.h`,两边共用:

```cpp
void utf8Truncate(char *dst, const char *src, size_t maxBytes);   // 保证不切断字符
```

> **教训:凡是"截断字符串"的地方都要用同一个工具函数。**
> 靠自觉每次都写对是不现实的 —— 这次就是第三次踩。

# 日志的局限

| 项 | 说明 |
|---|---|
| **只存在板子上** | 内存环形缓冲(150 行),**重启就没了** |
| **不会上传服务器** | 控制中心看不到流程日志(只有心跳) |
| **满了会顶掉最旧的** | 所以长时间跑建议定期清空 + 看 |

> 如果需要"日志持久化 / 远程看历史日志",可以再加:
> 板子把日志随心跳上报,服务器存表。**现在是没做的。**
