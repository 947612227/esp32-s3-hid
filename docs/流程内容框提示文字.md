# 流程内容框的占位提示

## 现象

新建流程时,「流程内容」框里显示三行:

```
T 0.5 0.5 60
wait 300
S 0.5 0.75 0.5 0.25 260
```

看着**像已经填好的默认内容**,让人以为要手动删掉。

## 真相

那是 **hint(占位提示)**,不是真内容 ——
`bodyEd.setHint("T 0.5 0.5 60\nwait 300\nS ...")`。

提示只在框为空时显示,一输入就没了。但**三行示例太长,视觉上和真内容没区别**,
而且**聚焦后还挂着**,所以很容易误判。

## 改法

1. **缩成一行**:
   ```
   例:T 0.5 0.5 60 · 或点上方「指令库」插入
   ```
2. **聚焦时直接隐藏** —— 手指一碰输入框,提示就消失,只剩光标:

```java
final String BODY_HINT = "例:T 0.5 0.5 60 · 或点上方「指令库」插入";
bodyEd.setHint(BODY_HINT);
bodyEd.setOnFocusChangeListener(new View.OnFocusChangeListener() {
    @Override public void onFocusChange(View v, boolean has) {
        bodyEd.setHint(has ? "" : BODY_HINT);   // 聚焦就清掉
    }
});
```

## 实测

| 状态 | 内容框 |
|---|---|
| 未聚焦(空) | `例:T 0.5 0.5 60 · 或点上方「指令库」插入` |
| **点进去** | **空**(只剩光标)✅ |
| 键盘 | 正常弹出,不再自动收 ✅ |

## 教训

> **占位提示不要写多行,也不要在聚焦后继续显示。**
>
> 多行示例会被当成"默认内容";聚焦后还显示,会让人以为"这东西删不掉"。
